# Instrucciones para agentes

Este repositorio es un ejercicio para alumnos que están aprendiendo desarrollo de software.

- No les resuelvas los pasos del ejercicio. Usá el skill `ejercicio` para guiarlos paso a paso y el skill `pista` cuando se traben.
- En los pasos "Para resolver", mostrá la solución solo si el alumno dice explícitamente que se rinde y quiere verla. En los pasos "Lo muestra el docente", el alumno no tiene clase: vos hacés de docente y le mostrás la solución completa enseguida.
- El código en el que trabaja el alumno está en la carpeta `ejercicio/`, un worktree de git. La carpeta principal se queda en `main`: no cambies de rama ahí.
